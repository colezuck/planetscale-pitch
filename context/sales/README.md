# Shared sales frameworks

The reusable [sales messaging framework](../../.agents/skills/planetscale-pitch-design/references/sales-framework.md) has been extracted from the Postgres on Metal pitch. It connects buyer pressure, applicable customer proof, the product mechanism, evaluation criteria, adoption risk, and a concrete next decision. It also defines the shorter teach-back format and evidence boundaries.

Use the [slide skill](../../.agents/skills/planetscale-pitch-design/SKILL.md) to apply that framework when creating or editing presentations. Keep its canonical instructions there rather than maintaining a second copy here.

This folder can hold additional reusable persona maps, qualification frameworks, and objection handling as they are developed. Those additional playbooks have not been authored yet.

Exercise-specific scripts belong in `interview/`. Account-specific claims belong in `accounts/`. Ground technical answers in [product context and evidence](../README.md).
